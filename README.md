## 🔧 Hardware Projects

### MnB Ultralight N17

The **MnB Ultralight N17** is our first hardware product — a compact, NEMA17-shaped CAN-FD expansion board designed for [RepRapFirmware](https://github.com/Duet3D/RepRapFirmware) and [Klipper](https://github.com/Klipper3d/klipper).

**Key Features:**
- 🔌 Mounts directly behind a NEMA17 stepper motor as a "motor backpack"
- 📡 CAN-FD communication for reliable, high-speed data transfer
- 🧠 RP2350A MCU with TMC2240 motor driver (up to 3A @ 36V)
- ⚡ Built-in braking resistor for overvoltage safety
- 🔓 Fully open source hardware and firmware

📦 **Repository:** [mettle-and-byte/ultralight-n17](https://github.com/mettle-and-byte/ultralight-n17)

🎯 **Firmware:** [mettle-and-byte/UltraFoCced](https://github.com/mettle-and-byte/UltraFoCced) — SimpleFOC-based firmware enabling closed-loop phase stepping control
